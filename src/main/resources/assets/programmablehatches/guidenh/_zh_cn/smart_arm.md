# 智能机械臂：按槽位表达式搬运

智能机械臂用表达式指定内部与外部槽位之间的映射。适合把原料放到固定位置、反转槽位顺序，或只处理一部分槽位。

## 先做一个一一对应的搬运

1. 把智能机械臂贴在具有物品栏的 GT 方块上，让该面正对另一个容器。
2. 选择“外部向内部”作为搬运方向。
3. 选择“映射 o→i”。这里 o 是外部槽位编号，表达式结果是内部槽位编号。
4. 输入表达式 `o`，使用静态模式并重新计算。
5. 在外部容器的几个不同槽位放少量物品，检查内部对应槽位。

槽位编号从 0 开始。内部槽位数少于外部容器时，超出内部范围的映射不会执行；先用探测窗口核对。

## 三个可直接观察的例子

| 目标 | o→i 表达式 | 观察方式 |
| --- | --- | --- |
| 相同编号对应 | `o` | 外部 0、1、2 分别进入内部 0、1、2 |
| 反转前 16 个槽 | `15-o` | 外部 0 进入内部 15，外部 15 进入内部 0 |
| 前 16 槽一一对应 | `o < 16 ? o : -1` | 只操作外部 0～15，其余映射被忽略 |

使用“映射 i→o”时，变量改为 i，表达式结果成为外部槽位。映射方向与实际搬运方向分别配置，可以用同一映射关系改变进出方向。

## 静态与动态

静态模式先生成映射表，再按表运行，适合固定槽位分配。修改表达式或更换相邻容器后重新计算，并查看状态是否就绪。

动态模式在运行时计算映射，允许读取机器启用状态与无线红石等信息。动态模式的最短工作间隔为 5 tick，静态模式可到 1 tick；实际搬运能力还取决于机械臂等级。

## 探测与错误定位

使用探测窗口选择槽位，查看表达式得到的目标编号。语法错误、目标不是容器、槽位越界等状态可帮助定位问题。先验证一个槽位，再测试整段映射。

如果同时有其他管道或覆盖板移动同一批物品，暂停其他搬运后单独验证机械臂，确认槽位对应关系再恢复完整物流。
