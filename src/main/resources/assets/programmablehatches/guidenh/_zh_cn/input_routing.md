# 远程输入、输入镜像与映射镜像

这几种设备分别解决远程访问容器、共享机器输入和扩展样板入口的问题。先确定要共享的是容器、加工输入，还是主仓的输入区。

| 设备 | 目标 | 适用场景 |
| --- | --- | --- |
| 远程输入总线／仓 | 另一个容器 | 让机器直接使用远处箱子或储罐的内容 |
| 二合一输入镜像 | 编程二合一输入仓 | 多处结构访问同一组隔离输入 |
| 物品／流体输入镜像 | 主仓第一个非空缓存中的对应内容 | 使用普通输入总线／仓的位置接入共享材料 |
| 输入区映射镜像 | 主仓的输入区 | 扩展物流入口或样板入口 |

## 远程访问一个箱子或储罐

1. 用三录仪记录目标容器的位置。
2. 手持记录好的三录仪左键点击远程输入仓／总线，设置目标。
3. 检查 GUI 中的目标信息和可访问内容。
4. 确认目标容器允许从远程仓指向的方向抽取，并保持目标区块加载。
5. 在实际多方块上执行一份配方，核对目标容器的扣料和机器输出。

远程输入在同一维度中工作。GUI 预览只展示有限槽位或种类；可访问内容以容器实际允许提取的内容为准。

## 用闪存绑定输入镜像

用闪存左键点击主二合一仓记录位置，再右键点击镜像完成绑定。二合一镜像保留输入隔离语义；物品或流体版本属于普通输入仓室，按它们的规则参与机器配方检查。

在两个输入位置共享同一材料时，用少量原料验证扣料归属、配方选择和产物返回路径。需要优先执行大批次或小批次时，检查主仓与镜像的缓存顺序选项。

## 扩展接口和样板入口

输入区映射镜像本身不作为多方块结构组件。将它绑定到主仓，再给映射位置接接口；ME 映射版本可放置额外样板。剪线钳可调整允许输入的面。

打开映射镜像后，先核对目标机器和坐标。高亮按钮帮助定位主仓，打开主机按钮用于检查真正承载缓存的仓室。

## 共享输入总线的电路

共享输入总线镜像覆盖板用于同步同频道总线的虚拟电路槽。选一个主总线安装编程器覆盖板，其余同频道总线安装镜像覆盖板。通过主总线切换电路，观察其他总线跟随。

批量复制固定虚拟物品时，可使用虚拟输入总线与闪存：先记录目标虚拟总线，再从已配置的源总线复制标记。保证目标区块加载，并核对复制后的标记列表。
