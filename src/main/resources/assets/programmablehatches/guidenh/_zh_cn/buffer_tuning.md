# 缓存、样板倍增与大数量投料

缓存仓把输入区收到的材料归入内部缓存，并为缓存记录一份输入。后续材料能按该记录的整份数量追加时，可以继续进入同一缓存。这个记录与机器配方表中的最小配方分别检查。

## 先看输入区，再看缓存

1. 用已验证的一份样板给机器投料。
2. 打开输入总成主 GUI，观察外部输入区。
3. 打开内部缓存窗口，查看记录的材料、现有数量和锁定状态。
4. 再提交同样一份，观察它追加到相同记录的缓存。
5. 改用另一组配方，检查它是否进入另一缓存。

保持每批材料的顺序与数量一致。判断问题时同时看样板、外部输入区和缓存记录。

## 什么是记录配方的整数倍

假设某个缓存初次记录的输入为 A×2、B×3：

| 后续输入 | 与记录的关系 |
| --- | --- |
| A×2、B×3 | 一份 |
| A×4、B×6 | 两份 |
| A×8、B×12 | 四份 |
| A×4、B×5 | 不能组成这份记录的整数份 |

初次记录的批次大小很重要。如果首次投入本来就是放大后的批次，缓存记录也以那一批为基础。更换样板倍增设置时，先完成旧批次并检查缓存记录，再测试新的批次。

普通缓存需要重新记录时，先加工完或回收材料，再把缓存的锁图标切到解锁状态。等空缓存的记录清除后，投入新的完整批次。

概率补货与循环缓存还有各自的数量规则，按 [概率样板](chance_sifter.md) 和 [循环样板](cyclic_patterns.md) 教程检查对应状态。

## 倍增与优化

样板优化设置决定是否允许优化，以及修改倍增参数还是直接修改样板。操作后展开样板详细信息，核对每一种输入和输出的最终数量，再提交一份验证。

编程器电路与真实消耗原料分别处理。若放大样板把编程器电路一起增加，可以按实际需要使用样板标准化工具，将其数量设回 1；具体模式见 [工具与升级](tools_upgrades.md)。

## 缓存优先级与排队

缓存顺序选项可优先处理份数最多或最少的缓存。多个不同配方排队时，先准备一大一小两批，观察机器选择的缓存。镜像可跟随主仓或使用其支持的顺序设置。

同配方缓存合并选项改变向主控呈现缓存的方式。无尽缓冲提供额外的临时排队空间。分别启用并用小批量观察效果，确认下游吞吐足够后再增加订单。

## 超过普通整数范围的数量

仓室的内部存储、GUI 显示和多方块主控能够识别的输入范围是三个层面。大数缓存使用支持的大数量表示，主控端仍按它自己的兼容能力处理。

使用容量限制等设置，让输入处于目标机器支持的范围。单次输入作为完整批次检查，不依赖自动拆成若干个 int.max 小槽来建立新记录。遇到拒收或“非整数倍”提示时，核对记录数量、当前批次和限制选项。

手动取放时也检查剩余容量。例如容量 100、已有 40、手持 64，正确结果应是放入 60、手中留下 4。操作后查看 GUI 的精确数量，再保存和重开确认。
