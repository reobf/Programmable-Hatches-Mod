# 合成吞吐：转储器、请求拦截器与多方块 CPU

先确认瓶颈发生在原料发配、编程器电路供应，还是加工机器本身，再选择对应的设备。

## 合成转储器：增加成功发配后的重试

合成转储器在样板成功发配后增加重试机会，而这些重试不消耗额外并行。适合接收端有大量缓存、原料能够持续接收的场景。

1. 在合成 CPU 结构中使用相应等级的转储器。
2. 准备一张稳定加工样板和能够接收多份原料的输入总成。
3. 下单一批产物，比较接收端缓存填充速度。
4. 观察机器实际加工速度和输出是否跟得上。

转储器改善的是发配吞吐。机器配方执行速度仍由实际机器的功率、并行和工作状态决定。

## 大提供器的数量设置与升级芯片

需要大量编程器电路时，先使用 [大型提供器教程](large_provider.md) 中的并行单元和单次提供数量设置。升级芯片提供瞬时完成支持，普通模板仍保存在提供器里。

把编程器电路供应和主加工步骤分别测试：先直接下单电路，再下单使用它的产物，确认等待发生在哪一段。

## CPU 提取请求拦截器

编程器电路版本阻止 CPU 使用网络库存里的编程器电路，使这类需求通过提供器合成。通用版本可以指定要拦截的物品。

将拦截器连接到对应网络，再用小订单观察合成计划。启用前确保被拦截的材料有可用的合成来源；库存中已有该材料并不等于 CPU 会使用它。

## 多方块合成 CPU

多方块 CPU 从输入总线里的合成存储器分配任务所需 CPU。任务提交时分配所需存储器，完成后退回输出总线；奇点存储器按其特殊规则使用。

1. 按蓝图完成结构并提供供能和维护。
2. 在输入总线放入合成存储器与需要的并行核心。
3. 预留输出空间，提交一个小合成任务。
4. 观察分配、执行和存储器退回。
5. 使用螺丝刀按设备说明退回并行核心。

并行核心由该多方块分配出的 CPU 共享。通过同时提交两个小订单观察共享关系，再配置更大任务。
